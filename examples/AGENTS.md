# AGENTS.md · 项目说明书（给 AI 看的）

> 放在项目根目录。每次开新会话，AI 都会读它，不用你重复交代一遍。
> 保持简短（<150 行），写「不随对话变化」的事实和规矩。

## 这个项目是什么
「每日简报小助手」：抓取 3 个信息源，生成一页静态 HTML 简报。
受众：我自己；目标：每天早上 8 点能打开看一眼。

## 怎么跑
- 纯静态，无需构建：`python3 -m http.server 8000` 后打开 `http://localhost:8000`
- 生成简报：`node scripts/build.mjs`
- 没有后端、没有数据库、不引入框架

## 技术约定
- 单文件优先；HTML/CSS/JS 不拆包，不装 npm 依赖（除非我明确同意）
- 中文界面；浅色主题；移动端可用
- 日期用 `YYYY-MM-DD`，时间统一按 `Asia/Shanghai`
- 所有外部链接必须带 `rel="noopener noreferrer"`

## 干活规矩
1. **一次只改一件事**，改完告诉我改了哪些文件。
2. 改之前先 `git status`；我要求「先看 diff」时，只给方案不要动手。
3. 不要自动 `git commit` / `git push`，由我确认后再执行。
4. 不编造 API；不确定的第三方接口，先让我给官方文档。
5. 任何删除文件、覆盖配置、发消息、发布的动作，先问我。

## 不要碰
- `.env`、`*.key`、任何含密钥的文件
- `.git/`、`node_modules/`、`dist/`

## 验收清单
- [ ] 页面能打开，控制台无报错
- [ ] 手机宽度 375px 下不横向滚动
- [ ] `git diff` 里没有超出本次需求的改动
