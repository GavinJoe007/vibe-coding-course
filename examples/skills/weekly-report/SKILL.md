# 周报生成器

## 何时使用
- 用户说「写周报」「总结一下这周」「帮我同步进展」
- 每周五的定时汇报任务
- **不要**在用户只是问某个具体提交内容时使用

## 步骤
1. 在项目根目录运行 `git log --since="7 days ago" --pretty=format:"%s"`，收集本周提交。
2. 若提交为空，明确告知「本周没有提交记录」，并询问是否有口头进展，**不要编造**。
3. 按「已完成 / 进行中 / 风险与下周」三类归并；同类型的多条提交合并成一条。
4. 读取 `assets/template.md`，按模板填充输出。
5. 输出后问一句：「需要我把它写成 `docs/weekly-YYYY-MM-DD.md` 吗？」得到确认才写文件。

## 输出约束
- 每条一句话，不超过 25 个汉字，动词开头。
- 只写提交历史里能找到的事实；数字、日期必须来自 git log。
- 不写人名、客户名、密钥、内部链接等敏感信息。
- 用中文，不用 emoji，不加客套话。

## 示例
输入（git log）：
```
feat: 增加一键清空
fix: 刷新后勾选状态丢失
docs: 补充 README 运行说明
```
输出：
```
## 已完成
- 增加一键清空功能
- 修复刷新后勾选状态丢失
- 补充 README 运行说明
## 进行中
（无）
## 风险与下周
（无）
```
